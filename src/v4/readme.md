# V4：物体中心周围3厘米选点

独立来源：F:/jinsai/vision_versions_20261029/v1。V1原目录不修改。

工程入口：F:/jinsai/vision_versions_20261029/v4/vivado/v4.xpr。
本版下载文件：F:/jinsai/vision_versions_20261029/v4/release/v4.bit；对应探针v4.ltx。

## 唯一运行功能改动

第一次选物体时，原模型识别出的手指位置必须进入以物体中心为圆心、桌面实际半径30毫米的圆内，包含边界；仍要求连续3个稳定识别结果。锁定的是物体中心坐标。

换算沿用V1现有工作平面：X=-11～11厘米，Y=10～25厘米，模型坐标0～95。按两个方向各自的毫米比例计算圆内距离，不把3厘米误写成3像素，也不使用方形范围。换工作范围时需同步更新距离换算。

此功能使用原模型已有的手指坐标，不增加新模型或手指朝向推断。实际精度受原模型定位和原平面标定精度影响。

## 完全沿用V1的后续流程

1. 第一次锁定后，PL_LED0闪烁，等待手移开。
2. 连续2个无手结果后，等待第二次选点。
3. 第二次仍按V1规则：同时检出手指及原物体，锁定手指坐标；不要求手指仍在物体3厘米范围内。
4. 第二点锁定后PL_LED0停止闪烁，手再次移开后执行原抓取、搬运、放下、返回流程。

模型、摄像头通路、机械臂姿态、0号舵机驱动、复位参数、动作顺序、XY镜像、Z高度和按键逻辑均按复制时的V1原样保留。本版不包含其他待办修复。

运行scripts/test_v4_radius.ps1验证圆内判断与选点流程；运行scripts/test_coordinates.ps1验证三个完整抓放案例，逐字节对照V1的原UART指令。
